Qu'est-ce que K ?

K = nombre d'options candidates par avion (incluant l'option no-op « ne rien faire »). Variables binaires = n·K = qubits ; espace de recherche = K^n. K=3 par défaut pour la démo (équilibre couverture/qubits). Changer K change la discrétisation : les comparaisons entre méthodes ne sont valides qu'à K identique.

    QUBO reformulation

    Each aircraft picks one maneuver option (one-hot). The ACRP becomes min H(x) = Σ cost·x + λpen·Σ conflict·x·x + λoh·Σ(Σx−1)². Solve it three ways on the same matrix: exact, simulated annealing, or QAOA.
